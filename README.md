# Frontend Mentor - Hotel booking confirmation page

## Overview

This project recreates the Frontend Mentor hotel booking confirmation page using semantic HTML, Tailwind CSS, and a very small `input.css` file. The goal was to match the supplied desktop and mobile designs while keeping the layout responsive and accessible.

## Approach

I built the page in progressive sections across multiple Git commits. I started with the Tailwind setup and desktop sidebar, then added the booking header, receipt card, host note, and guest information cards. Tailwind utility classes handle nearly all spacing, color, layout, borders, responsiveness, hover states, and typography.

## Challenges

The most challenging parts were the layered receipt/host cards and making the sidebar work well across desktop and mobile sizes. I solved these by using responsive Tailwind utilities, grid/flex layouts, and small rotation/spacing adjustments.

## Built with

- Semantic HTML5
- Tailwind CSS v4
- Tailwind CLI
- Minimal custom CSS
- Responsive/mobile-first utilities
