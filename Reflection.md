# Reflection

The biggest challenge was recreating the layered card layout while keeping the page responsive. I first separated the design into smaller sections: sidebar, booking header, receipt, host note, and guest information cards. Building one section at a time made it easier to compare my work to the reference design and fix spacing problems.

Tailwind simplified the project because I could handle layout, spacing, borders, colors, hover states, and breakpoints directly in the HTML. I only kept a small `input.css` file for Tailwind and basic global styles.

If I had more time, I would fine-tune the spacing and typography at additional screen sizes and add the optional JavaScript features, such as copying the Wi-Fi password and opening the mobile navigation menu.
